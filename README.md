# AI Data Analysis Assistant

## Project Overview
A Python-based data analysis assistant that allows users to upload CSV datasets, ask predefined natural language questions, generate visualizations, and explore automated findings.

## Features
- CSV file upload and reading
- Dataset overview and preview
- Natural language question processing
- Missing value analysis
- Average, highest, and lowest value analysis
- Correlation analysis
- Frequency distribution
- Histogram and box plot generation
- Automated statistical findings

## Technologies
- Python
- Pandas
- Streamlit
- Matplotlib

## How to Run

Install the required packages:

```bash
pip install pandas streamlit matplotlib
```

Run the application:

```bash
streamlit run ai_data_assistant.py
```

## Supported Questions
- Show dataset summary
- Show missing values
- What is the average?
- Show the highest value
- Show the lowest value
- Show correlation
- Show frequency distribution

## Project Limitation
This educational prototype uses predefined question patterns and statistical analysis. It does not use a generative AI language model.
